Ejercicios para pensar y aplicar

Este material complementa las fichas: incluye ejemplos resueltos, preguntas de recuperación activa y un plan de estudio. Intenta responder antes de abrir la explicación.

Método de 3 pasos
  1. Lee la pregunta o ejercicio.
  2. Resuélvelo en una hoja.
  3. Compara y explica el porqué.
  4. Practica el tema en el simulador.

No memorices solo frases. Para cada respuesta, pregúntate: “¿por qué es correcta?” y “¿en qué caso real se aplicaría?”. Así estarás preparado para preguntas distintas en el examen.

Ejemplos resueltos

Fundamentos de programación

Promedio de tres notas

Identifica entradas, proceso y salida antes de programar.

Leer n1, n2, n3
promedio = (n1 + n2 + n3) / 3
Mostrar promedio

Idea clave: un algoritmo es una secuencia precisa; promedio es una variable que almacena el resultado.

Matemática discreta

Convertir 13 decimal a binario

Divide entre 2 y lee los residuos de abajo hacia arriba.

13 ÷ 2 = 6, residuo 1
 6 ÷ 2 = 3, residuo 0
 3 ÷ 2 = 1, residuo 1
 1 ÷ 2 = 0, residuo 1
Resultado: 1101₂

Comprobación: 1×8 + 1×4 + 0×2 + 1×1 = 13.

Estadística

Media de tres datos

Para las notas 7, 8 y 9, se suma y divide para el número de datos.

media = (7 + 8 + 9) / 3
media = 24 / 3 = 8

Idea clave: la media resume el centro; no explica por sí sola la dispersión de las notas.

Bases de datos

Cliente y pedido: relación 1 a N

Un cliente puede realizar muchos pedidos; cada pedido corresponde a un cliente.

CLIENTE(id_cliente, nombre)
PEDIDO(id_pedido, fecha, id_cliente)

PEDIDO.id_cliente → CLIENTE.id_cliente

Idea clave: id_cliente es clave foránea dentro de PEDIDO.

SQL y transacciones

Transferencia segura

Las operaciones relacionadas deben completarse juntas o revertirse.

BEGIN TRANSACTION;
UPDATE cuenta SET saldo = saldo - 50 WHERE id = 1;
UPDATE cuenta SET saldo = saldo + 50 WHERE id = 2;
COMMIT;

Si falla algo: ROLLBACK revierte ambas operaciones. Esto muestra atomicidad.

POO

Clase y objeto

Una clase define atributos y comportamientos; un objeto es un caso concreto creado desde ella.

Clase Estudiante
  atributo nombre
  método presentarse()

Objeto: Ana, nombre = "Ana"

Idea clave: Estudiante es el molde; Ana es un objeto.

Metodologías ágiles

Tablero Kanban

Visualiza el trabajo y detecta tareas que se acumulan.

Pendiente → En proceso → Terminado
"Diseñar login" → "Probar login" → "Publicar"

Idea clave: demasiadas tareas “En proceso” indican un posible cuello de botella.

Redes

¿TCP o UDP?

La elección depende de confiabilidad y latencia.

Archivo importante → TCP
Video o voz en tiempo real → puede usar UDP

TCP confirma; UDP reduce sobrecarga.

Idea clave: no hay uno “mejor” siempre; depende del caso de uso.

Web y APIs

Recurso REST de productos

Una API representa recursos mediante rutas y métodos HTTP.

GET    /productos      → listar
GET    /productos/5    → consultar uno
POST   /productos      → crear
PATCH  /productos/5    → actualizar parte
DELETE /productos/5    → eliminar

Idea clave: el método HTTP expresa la intención de la operación.

Diseño de interfaz

Validar con un prototipo

Un prototipo permite probar el flujo antes de construir toda la aplicación.

Tarea: reservar una cita
1. Elegir fecha
2. Elegir horario
3. Confirmar datos
4. Recibir confirmación

Idea clave: si el usuario no entiende un paso, corrige el diseño antes de programarlo.

Proyecto de investigación

Del problema al objetivo

El objetivo debe responder al problema de forma concreta y delimitar el alcance.

Problema: demoras al registrar citas.
Objetivo: diseñar un prototipo para
agilizar el registro de citas.

Idea clave: “diseñar” indica una acción; el alcance aclara qué incluirá el prototipo.

Inglés A1–A2

Pregunta y comparativo

Con you se usa Do; muchos adjetivos cortos añaden -er en comparativo.

Do you like coffee?
A bike is cheaper than a car.

Idea clave: cheap cambia a cheaper al comparar dos elementos.

Autoevaluación por materia

1. ¿Qué diferencia hay entre variable y constante?

Una variable puede cambiar de valor durante el programa; una constante se mantiene fija dentro del contexto definido.

Ejemplo: total cambia al calcularse; un porcentaje de IVA puede tratarse como constante.

2. ¿Cuándo una proposición “A Y B” es verdadera?

Solo cuando A y B son verdaderas. Si una es falsa, la conjunción completa es falsa.

Ejemplo: “Tengo Internet Y el servidor responde” requiere ambas condiciones.

3. ¿Por qué usar una referencia absoluta en una hoja de cálculo?

Para mantener fija una celda al copiar una fórmula a otras posiciones.

Ejemplo: =B2*$E$1 conserva fijo el porcentaje de E1.

4. ¿Qué es un requerimiento funcional?

Describe una función o servicio que el sistema debe proporcionar; un no funcional describe una cualidad o restricción.

Ejemplo: “Registrar usuario” es funcional; “responder en menos de 2 segundos” es no funcional.

5. ¿Qué representa una clave foránea?

Es un campo que referencia la clave primaria de otra tabla y permite relacionar registros.

Ejemplo: pedido.id_cliente referencia cliente.id_cliente.

6. ¿Qué información aporta la desviación estándar?

Indica cuánto tienden a alejarse los datos de su media. Una desviación mayor suele significar mayor variabilidad.

Recuerda: interpreta media y dispersión de manera conjunta.

7. ¿Para qué sirve una excepción en POO?

Representa un error o condición excepcional que puede manejarse sin detener la aplicación de forma descontrolada.

Ejemplo: capturar el error al abrir un archivo inexistente y mostrar un aviso.

8. ¿Qué busca el Manifiesto Ágil?

Promueve colaboración, entrega frecuente de software útil, adaptación al cambio y comunicación con personas involucradas.

Recuerda: ágil no significa trabajar sin planificación ni documentación.

9. ¿Qué propiedad ACID evita una transacción a medias?

La atomicidad: una transacción se completa por entero o se revierte por completo.

Ejemplo: una transferencia no debe descontar dinero sin acreditarlo en destino.

10. ¿Cuál es la diferencia principal entre TCP y UDP?

TCP entrega datos de manera confiable con conexión, confirmaciones y retransmisiones; UDP no garantiza entrega, pero tiene menor sobrecarga.

Aplica: TCP suele servir para archivos; UDP puede ser útil en tiempo real.

11. ¿Qué hace HTML, CSS y JavaScript?

HTML estructura contenido, CSS define presentación y JavaScript agrega comportamiento e interacción.

Ejemplo: un formulario usa HTML, tiene estilo con CSS y se valida con JavaScript.

12. ¿Por qué una app móvil debe manejar falta de conexión?

Porque la conectividad puede ser intermitente. La app debe informar, guardar localmente o sincronizar cuando exista red.

Idea clave: no asumir conexión constante evita pérdida de datos.

13. ¿Cómo se reconoce una interfaz usable?

Permite completar tareas con eficacia, eficiencia y satisfacción, con errores mínimos y comprensión clara.

Ejemplo: etiquetas claras, retroalimentación y navegación consistente mejoran la usabilidad.

14. ¿Qué diferencia hay entre sexo y género?

Sexo se relaciona con características biológicas; género se refiere a roles, identidades y construcciones sociales.

Aplica: distinguirlos ayuda a evitar estereotipos y promover equidad.

15. ¿Cuál es la estructura básica de un ensayo?

Introducción con tema o tesis, desarrollo con argumentos y evidencia, y conclusión que sintetiza la postura.

Consejo: cada párrafo debe aportar una idea conectada con la tesis.

16. ¿Qué problema busca resolver la normalización?

Busca disminuir redundancia y anomalías al insertar, actualizar o eliminar datos, organizando tablas según dependencias.

Ejemplo: evitar repetir datos completos de un cliente en cada pedido.

17. ¿Qué diferencia hay entre RA y RV?

La realidad aumentada añade contenido digital sobre el mundo real; la virtual crea un entorno digital inmersivo.

Ejemplo: un filtro de cámara es RA; un visor inmersivo representa RV.

18. ¿Qué necesita una API REST segura?

Autenticación, autorización, validación de datos, manejo seguro de errores y HTTPS en un entorno real.

Recuerda: un JWT firmado no debe contener secretos, porque su contenido puede leerse si no está cifrado.

19. ¿Qué es una propuesta de valor?

Explica por qué una solución es útil para un segmento de clientes y qué necesidad resuelve de manera diferenciada.

Ejemplo: “Entregar productos locales frescos a domicilio el mismo día”.

20. ¿Qué deben responder las conclusiones de un proyecto?

Deben responder objetivos usando resultados obtenidos, sin inventar información nueva ni repetir solamente la introducción.

Consejo: relaciona cada conclusión con evidencia o indicador del proyecto.

21. Completa: “She ___ to class every day.”

La respuesta es goes, porque con she en presente simple se usa la tercera persona singular.

Oración: She goes to class every day.
